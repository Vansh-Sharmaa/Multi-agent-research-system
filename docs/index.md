# Intellecta Multi-Agent Research System

Welcome to **Intellecta** — an autonomous multi-agent AI engine designed to conduct deep web research on any given topic.

## Overview

Intellecta orchestrates a network of specialized AI agents built on **LangGraph** and **LangChain** to:
- Search the web for relevant resources
- Scrape and extract deep content
- Compile comprehensive markdown reports
- Critically review outputs for quality

All powered locally and privately using **Ollama** and **Llama 3.1**.
